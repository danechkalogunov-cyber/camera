# Vigil — как запустить

Приложение для просмотра камер Hikvision в локальной сети. Ниже — самый короткий путь от нуля до
картинки с камеры.

---

## Шаг 1. Один раз: инструменты

Нужен Mac с **macOS 14 (Sonoma) или новее** и компилятор Swift. Если Xcode уже стоит — ничего делать
не надо. Если нет, достаточно инструментов командной строки:

```bash
xcode-select --install
```

Проверить, что всё на месте:

```bash
swift --version
```

Должно напечатать версию Swift 6 или новее. Если пишет, что команда не найдена — Xcode
или инструменты не установились, повторите команду выше.

---

## Шаг 2. Собрать и запустить

```bash
cd путь/к/camera
Scripts/run.sh
```

Это соберёт приложение, запустит его и **выведет журнал прямо в это окно терминала** — так что если
камера не подключится, причина будет видна здесь, а не в Console.app.

Первая сборка занимает несколько минут: компилируется около 190 файлов. Дальше — секунды.

Если хотите просто собрать, не запуская:

```bash
Scripts/build-app.sh
```

Готовое приложение окажется в `dist/Vigil.app`. Его можно перетащить в «Программы» и запускать как
обычное приложение.

---

## Шаг 3. Подключить камеру

1. Приложение спросит **адрес камеры** и **пароль**. Больше ничего вводить не нужно.
2. Имя пользователя уже подставлено — `admin`, как на Hikvision по умолчанию. Если у вас другое,
   поменяйте.
3. Адрес — это IP камеры в вашей сети, например `192.168.1.64`. Посмотреть можно в роутере или в
   утилите SADP от Hikvision.
4. Нажмите Return.

**RTSP-адрес, номер канала, кодек и транспорт вводить не нужно** — приложение подбирает их само,
перебирая известные варианты Hikvision, и запоминает подошедший. При втором запуске не нужно
вводить вообще ничего: адрес, учётная запись и найденный путь сохраняются, пароль лежит в связке
ключей macOS.

## Если что-то пошло не так

### macOS спросит доступ к локальной сети

Разрешите. Без этого приложение не сможет обратиться к камере — это требование macOS 14, а не наша
прихоть.

### «Приложение из неопознанного источника»

Сборка подписывается ad-hoc, то есть годится для запуска на той машине, где собрана, но не проходит
Gatekeeper. Если система не пускает:

```bash
xattr -dr com.apple.quarantine dist/Vigil.app
```

### Камера не подключается

Приложение не показывает коды ошибок — оно называет причину словами и говорит, что делать. Девять
разных диагнозов: неверный пароль, камера не активирована, учётная запись заблокирована, порт RTSP
закрыт, устройство не Hikvision, UDP блокируется, нет ключевого кадра и так далее.

Если хочется подробностей, запустите с журналом только по нужной части:

```bash
Scripts/run.sh --category rtsp      # переговоры с камерой
Scripts/run.sh --category rtp       # приём видеопакетов
Scripts/run.sh --category decode    # декодирование
```

### Сборка падает с ошибками компиляции

Это возможно и ожидаемо на первом запуске, и вот почему честно: **около трети кода писалось в
Linux-контейнере, где нет ни Xcode, ни фреймворков Apple.** Всё, что работает с VideoToolbox, Metal,
AppKit и Network.framework, впервые встретится с компилятором именно у вас. Протокольная часть —
RTSP, RTP, разбор H.264/H.265 — собрана и покрыта 1229 тестами, а вот платформенная обвязка
проверена только вычиткой.

Если сборка упала — **пришлите вывод целиком**, ошибки такого рода чинятся быстро.

## Что уже умеет прототип

- Одна камера, живое видео, аппаратное декодирование
- H.264 и H.265 (Hikvision по умолчанию отдаёт H.265 на свежих прошивках)
- RTSP поверх TCP, авторизация Digest
- Пароль в связке ключей, никогда не в файлах и не в журнале
- Автоподбор RTSP-пути, автопереподключение с нарастающей паузой
- Понятная диагностика вместо кодов ошибок

## Чего пока нет

Сетка из нескольких камер, PTZ, архив с таймлайном, события и уведомления, запись, скриншоты,
автопоиск камер в сети, звук, русский интерфейс. Всё это в работе.

## Полезное

| Команда | Что делает |
|---|---|
| `Scripts/run.sh` | собрать, запустить, показать журнал |
| `Scripts/run.sh --no-build` | запустить уже собранное |
| `Scripts/build-app.sh` | только собрать в `dist/Vigil.app` |
| `Scripts/build-app.sh --configuration debug` | отладочная сборка |
| `Scripts/check.sh` | прогнать линтер, сборку и тесты |

Подробности для разработчика — в `README.md` и `docs/`.
